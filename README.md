# 📞 Phone Book Application | Python

## Project Overview

The Phone Book Application is a simple contact management project developed using Python in Jupyter Notebook.

It allows users to manage their contact information through basic operations such as adding, viewing, searching, and deleting contacts. The project demonstrates the practical use of Python programming concepts to build a simple and useful application.

## Features

- **Add Contact:** Add a new contact with a name and phone number.
- **View Contacts:** Display all saved contacts.
- **Search Contact:** Search for a contact using their name.
- **Delete Contact:** Remove an existing contact from the phone book.

## Technologies Used

- Python
- Jupyter Notebook

## Python Concepts Used

- Variables and data types
- Dictionaries
- Conditional statements
- Loops
- Functions
- User input and output
- Basic data management

## How It Works

1. Run the Python code in Jupyter Notebook.
2. Select an operation from the available menu.
3. Enter the required contact information.
4. Add, view, search, or delete contacts.
5. The application displays the result based on the selected operation.
